\sectiontitle{实习与研究经历}{Research Experience}
\entryhead{腾讯 PCG · QQ 影像研究中心}{流式可交互音视频生成（LTX-2.3 22B）}{2026.06--2026.09}
\begin{tightitems}
  \item \itemtag{因果建模}将双向 LTX-2.3 改为\textbf{块因果音视频生成模型}，按 1 秒对齐不同帧率的音视频 latent，为模态内及跨模态注意力设计因果掩码，支持按块联合生成。\href{https://longxiao2001.github.io/StreamLTX/}{[Project Page]}
  \item \itemtag{训练与蒸馏}采用 Teacher / Diffusion / Resample Forcing 分阶段训练：引入块级独立噪声，以\textbf{模型 rollout 历史作为监督条件}，针对训练与推理的历史分布偏差训练。各阶段共用 RoPE 索引与稀疏因果掩码，单次前向监督多个块；将采样由 30 步蒸馏至\textbf{4 步}。
  \item \itemtag{长程记忆}将 KV 缓存分为锚点、历史记忆和近期窗口，结合注意力得分与时间多样性筛选历史，固定缓存预算，支持\textbf{十分钟级连续生成}。
  \item \itemtag{在线交互}拆分承载场景、角色与风格的 Global Prompt，以及承载动作与台词的 Local Prompt；限制当前块只关注对应的局部文本条件，支持\textbf{生成过程中更新指令}。
  \item \itemtag{并行推理}按去噪阶段组织多卡流水，每卡保留对应阶段的 KV，通过 NCCL P2P 传递 latent；结合 FA3，在\textbf{4×H800、512×768} 下达到\textbf{43 fps} 的 DiT 稳态去噪吞吐。
  \item \itemtag{实时生成}实现\textbf{端到端实时音视频生成}；首帧需完成四步流水预热（约\textbf{2 s}），VAE 解码与Prompt编码异步进行。同配置基线采用 30 步非时间步并行推理，单步约 0.4 s。
\end{tightitems}

\entryhead{阿里巴巴 · 优酷}{视频局部重绘与表情编辑}{2025.10--2026.04}
\begin{tightitems}
  \item \itemtag{可控重绘}基于 Wan2.2，以\textbf{逐帧向量化 timestep} 控制噪声强度，实现指定时间段重绘，无需新增掩码分支；对条件帧按编辑强度加噪，并沿缩放后的噪声轨迹去噪。
  \item \itemtag{训练适配}针对编辑边界的 adaLN 调制突变，引入时间步线性过渡，按训练进度调配同步、随机异步和连续段重绘任务；为高、低噪专家分别训练 LoRA，适配逐帧编辑条件与推理时的专家路由。
  \item \itemtag{数据与评测}搭建 UE Metahuman 表情参数提取与 3D 动画渲染管线，构建表情迁移评测集和数据筛选流程，用于\textbf{PerformRecast（CVPR 2026）}。\href{https://youku-aigc.github.io/PerformRecast/}{[Project Page]}
\end{tightitems}

\entryhead{右脑科技}{数字人生成与论文讲解视频 Agent}{2025.06--2025.10}
\begin{tightitems}
  \item \itemtag{数字人生成}基于 VACE、LivePortrait 融合姿态、文本与音频条件，通过分段生成和跨片段衔接扩展时长；采用 CausVid 蒸馏与权重动态加载，在\textbf{单张 RTX 4090} 上运行 VACE 14B。
  \item \itemtag{视频 Agent}使用 LangGraph 构建论文解析、脚本生成到视频合成的流程，以\textbf{TTS 字符级时间戳}确定分镜时长，对齐幻灯片、口播与数字人画面；支持分镜并行生成、失败重试与工具降级。
\end{tightitems}

\entryhead{腾讯 IEG · 光子}{交互游戏 NPC 与语音驱动表情生成}{2025.02--2025.06}
\begin{tightitems}
  \item \itemtag{语音交互}集成\textbf{ASR-LLM-TTS-UE} 交互链路，完成模块接口与推理联调，并按环节分配时延预算。
  \item \itemtag{表情生成}基于前期语音驱动表情工作继续开发：以冻结的 WavLM-Large 语音特征、情绪和历史表情为条件，用 MDM Transformer 在\textbf{185 维 Metahuman 控制参数}上进行扩散生成；引入速度损失约束抖动，通过滑窗与重叠混合衔接长音频。
\end{tightitems}
